# Сравнение Git и SVN

## Почему ветвление в Git «дешёвое», а в SVN — «дорогое»?

В Git ветка — это небольшой локальный указатель на коммит, поэтому она создаётся почти мгновенно и не копирует файлы. В SVN ветвление исторически реализовано как серверное копирование каталога. Хотя SVN использует «дешёвые копии», такая операция сильнее зависит от структуры центрального репозитория и сетевого взаимодействия.

## Можно ли сделать коммит в SVN без интернета?

Обычно нет. SVN — централизованная система, поэтому коммит должен быть отправлен на центральный сервер. В Git коммиты создаются в локальном репозитории и могут быть отправлены позже.

## Когда SVN может быть предпочтительнее Git?

SVN может быть удобен в legacy-проектах с уже построенной вокруг него инфраструктурой, при необходимости централизованного контроля доступа к отдельным каталогам, а также для больших наборов бинарных файлов, когда пользователям не нужна полная локальная история репозитория.
