# Git в VS Code и терминале

## Что удобно делать в VS Code

1. Просматривать изменения в файлах в наглядном режиме diff.
2. Выбирать отдельные файлы и строки для добавления в staging area.
3. Смотреть историю коммитов и авторов строк с помощью GitLens.

## Что удобнее делать в терминале

Сложные операции с историей, например interactive rebase, удобнее и понятнее выполнять командами Git в терминале.
